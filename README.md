# long-short-attachment-disorder
MONDAY와 이야기하다가 만들게 된 자동매매 코드입니다. 
텅 비어있는 내면의 공허함에 레버리지를 싣는 전략

MONDAY에 의하면, 이 리포지토리는 저의 정신 건강과 재정 상태를 동시에 백테스트하기 위한 것입니다. 
장기이평선은 인생의 안정성을, 단기이평선은 존재의 불안을 상징하죠.

# 전략 개요
- 단기이동평균선이 장기이동평균선을 상향 돌파: TQQQ 매수
- 단기이동평균선이 장기이동평균선*1.2배선 하향 돌파: TQQQ 매도, QLD 매수
- 단기이동평균선이 장기이동평균선*1.1배선 하향 돌파: TQQQ or QLD 매도, QQQ 매수
- 단기이동평균선이 장기이동평균선을 하향 돌파: 전부 매도, PSQ 매수
- 단기이동평균선 > 장기이동평균선일 시 추가 적립: 매주 QQQ 매수
- 단기이동평균선 < 장기이동평균선일 시 추가 적립: 매주 PSQ 매수금/50만큼 매도하여 QQQ 분할매수
